# Brief for a cloud session (Opus, ultracode on)

Repository: founder-birthdays (private). Read README.md, SCOPE.md, HYPOTHESES.md and VIDEO_SCRIPT.md first; the pipeline is in pipeline/ and the self-contained page is dist/index.html (open it in a browser, no build step).

What exists: a scroll-driven data story that places every founder of the world's biggest companies on a 365-day ring and tests, against Monte Carlo and permutation nulls, whether they cluster by Sun sign, element, modality, cofounder pairing, school-year position (relative age), or sign-by-sign pairing; the fallen companies and the cofounder breakups are separate rings and tests. Hypotheses were pre-registered in HYPOTHESES.md before any birth date was pulled. Every birthday carries a source URL; nothing was filled from memory.

Your job, in this order, committing after each step:
1. Missing birthdays. data/founders.json lists every founder; about half have no day-precision date. For each undated founder with a Wikipedia or Wikidata page, look for a reliable source that states day, month and year (Wikipedia lead or infobox, Wikidata with a cited reference, Britannica, a Bloomberg or Forbes profile, an official biography, a court filing, an obituary, a reputable newspaper). Never infer from an age or a birthday post. Write accepted dates into pipeline/birthday_overrides.json as {key: {birthday, source_url, source}} where key is the Wikidata Q-id or "name:<name>", then rerun pipeline/04_birthdays.py onward (see README for the order) and dist/index.html rebuilds. Have a second agent refute every date before it is accepted.
2. Astro-Databank birth times. research/adb_raw.json holds what has been read so far (page slug -> born on / place / timezone / Rodden rating). Only entries whose date matches ours are used. Extend it for founders not yet looked up (pipeline/adb_slugs.py prints candidate slugs); the site must be read in a real browser, one page per founder, and never with a replayed cookie.
3. Design polish on pipeline/template.html only (the build inlines data into dist/index.html): keep the dark canvas, amber headlines, mono captions and the ring as the hero; make transitions smoother, tighten the chapter layouts, and keep every label obvious to a first-time viewer. No new claims, no changes to the statistics, no new fonts loaded from the network (the page must stay self-contained).
4. Record nothing to video; the narration lives in VIDEO_SCRIPT.md and is regenerated by pipeline/11_script.py from data/stats.json so numbers always match the page.

Rules: python runs as `PYTHONPATH=pipeline python3 -P pipeline/<script>.py` (install pyswisseph, requests, numpy, scipy); never write a date from memory; keep "exploratory" labels on anything not in HYPOTHESES.md; the shell is zsh; never `sleep` in a foreground command; every subagent brief repeats these rules.
